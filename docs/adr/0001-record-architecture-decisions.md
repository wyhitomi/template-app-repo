# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-09-23

## Context

Decisions made in chats and meetings get lost; new joiners cannot tell why the
system looks the way it does, and settled debates get reopened.

## Decision

We will record architecturally significant decisions as ADRs in `docs/adr/`,
using the template in `0000-template.md`, reviewed through pull requests.

## Consequences

- **Positive:** decisions are discoverable, versioned and reviewed like code.
- **Negative:** small overhead per decision.
